# 基于SpringBoot的就业面试辅助系统

---

## 摘　要

随着高校毕业生数量的逐年攀升，就业竞争压力也在不断加剧，如何让求职者在有限的准备时间内最大化提升面试竞争力，已经成为一个值得深入探讨的现实问题。传统的面试备考方式过于依赖零散的网络资料和纸质书本，缺乏系统性和针对性，导致备考效率低下。本文设计并实现了一套基于SpringBoot框架的就业面试辅助系统，旨在为求职者提供一个集题库练习、AI模拟面试、知识库学习、错题管理、学习数据分析于一体的综合性备考平台。

系统在技术架构上采用前后端分离的设计思路，后端以SpringBoot 2.7.14为核心框架，结合Spring Data JPA实现数据持久化，数据库层面以H2作为开发环境内嵌数据库、MySQL 8.0作为生产环境数据库；前端基于Vue.js 2.6构建单页面应用，借助Element UI组件库完成界面设计，使用ECharts实现学习数据的可视化展示。系统整体通过RESTful API风格完成前后端数据交互，接口设计规范、扩展性强。

在功能层面，系统面向学生和教师两类用户角色设计了差异化的功能模块。学生端涵盖面试教程学习、题目分类练习、AI模拟问答、知识库浏览、错题本管理、收藏夹、学习报告以及个人中心等核心功能；教师端则提供题目管理、教程管理、课程管理和知识点管理等内容运营工具。其中，AI模拟面试模块通过接入智谱AI的GLM系列大语言模型，能够模拟技术面试、行为面试和HR面试三种真实场景，并在面试结束后自动生成评分与反馈报告，有效弥补了传统备考方式缺乏实战演练的短板。

经过系统测试，各功能模块运行稳定，接口响应及时，用户界面交互流畅，达到了设计目标。

**关键词：** SpringBoot；Vue.js；面试辅助；AI模拟面试；前后端分离

## Abstract

With the continuous growth in the number of college graduates, employment competition has become increasingly fierce. How to help job seekers maximize their interview competitiveness within limited preparation time has become a realistic problem worth exploring. Traditional interview preparation methods rely too heavily on scattered online resources and paper books, lacking systematization and targeting, resulting in low preparation efficiency. This paper designs and implements a job interview assistance system based on the SpringBoot framework, aiming to provide job seekers with a comprehensive preparation platform integrating question bank practice, AI mock interviews, knowledge base learning, wrong question management, and learning data analysis.

The system adopts a front-end and back-end separated design approach. The back-end uses SpringBoot 2.7.14 as the core framework, combined with Spring Data JPA for data persistence. H2 is used as the embedded database in the development environment and MySQL 8.0 as the production database. The front-end builds a single-page application based on Vue.js 2.6, using the Element UI component library for interface design and ECharts for visualization of learning data. The system completes front-end and back-end data interaction through RESTful API style with standardized interface design and strong scalability.

At the functional level, the system designs differentiated functional modules for two types of users: students and teachers. The student side covers core functions such as interview tutorial learning, question category practice, AI mock Q&A, knowledge base browsing, wrong question book management, favorites, learning reports, and personal center. The teacher side provides content operation tools such as question management, tutorial management, course management, and knowledge point management. Among them, the AI mock interview module, by integrating ZhipuAI's GLM large language model, can simulate three real interview scenarios: technical interviews, behavioral interviews, and HR interviews, and automatically generates scoring and feedback reports after the interview ends.

After system testing, each functional module runs stably with timely interface responses and smooth user interface interaction, achieving the design goals.

**Keywords:** SpringBoot; Vue.js; Interview Assistance; AI Mock Interview; Front-end and Back-end Separation

# 第1章 绪 论

## 1.1 研究背景

近些年，国内高校毕业生人数持续创下历史新高。据教育部数据，2024年全国高校毕业生数量突破1170万，就业市场供给端的压力已经相当明显。在这样的背景下，如何在众多求职者中脱颖而出，顺利通过企业的笔试和面试环节，是摆在每个应届毕业生面前的现实难题。

企业的招聘流程通常包含多个环节，面试是其中最关键的一环，也是筛掉大量候选人的主要关口。技术类岗位的面试往往涵盖算法题、数据结构、计算机基础知识、系统设计等多个维度，而行为面试和HR面试又需要求职者具备良好的表达能力和职业素养。这就意味着，仅仅掌握专业知识是不够的，还需要在真实的面试对话场景下进行大量刻意练习。

然而，当前市场上的备考工具普遍存在一些短板。一方面，像牛客网、LeetCode这类平台虽然题库资源丰富，但功能相对单一，且以算法竞技类题目为主，缺乏对面试真实场景的模拟；另一方面，很多求职者没有条件找到合适的面试伙伴进行模拟练习，导致上了面试现场才意识到自己表达不够清晰、逻辑不够流畅。此外，学习过程中产生的错题、笔记、收藏等数据没有得到有效管理，学习轨迹也缺乏可视化呈现，难以帮助用户找到自身的薄弱点并制定针对性的复习计划。

大语言模型技术的快速发展为解决上述问题提供了新的可能。以智谱AI的GLM系列模型为代表的国产大语言模型，已经具备了相当强的对话理解和生成能力，能够模拟面试官的提问风格，对候选人的回答进行实时评估，并给出有建设性的反馈意见。将这类AI能力集成到面试备考系统中，可以让用户随时随地进行高质量的模拟面试练习，有效填补了传统备考方式在实战演练上的空白。

## 1.2 研究目的及意义

本课题的核心目标是设计并实现一套完整的就业面试辅助系统，帮助求职者建立起系统化的面试备考体系。这套系统需要解决几个关键问题：其一，提供覆盖多个技术领域、多种题型的结构化题库；其二，实现基于大语言模型的AI模拟面试功能，让用户能够体验贴近真实的面试场景；其三，建立个人知识体系管理机制，包括知识点的学习进度追踪和错题的智能复习提醒；其四，通过数据分析和可视化手段，让用户清晰地看到自己的学习轨迹和能力成长曲线。

在实践意义上，该系统的完成直接对求职者产生帮助。对于在校学生而言，可以利用碎片化时间随时刷题练习，通过AI面试功能锻炼表达能力，不再受时间和地点的限制。对于应届毕业生和在职人员，系统提供的数据报告能够帮助他们快速定位薄弱环节，做到有针对性地查漏补缺，而不是漫无目的地盲目刷题。

在学术意义上，本项目综合运用了SpringBoot、Vue.js、Spring Data JPA、Element UI等主流开发技术，并探索了大语言模型在垂直领域应用落地的实践路径，是一次将前沿AI技术与实际工程需求相结合的有益尝试，也为类似的教育类辅助系统的开发提供了可参考的架构范式。

## 1.3 国内外研究现状

### 1.3.1 国内研究现状及分析

国内在面试辅助和在线教育领域已经形成了较为成熟的产品生态。牛客网是目前国内最具代表性的面试备考平台之一，它汇聚了大量的笔试真题和企业面经，并提供了在线编程环境，深受计算机专业求职者的青睐。LeetCode中国版也在国内积累了大量用户，尤其在算法题训练方面有较强的竞争力。此外，面试鸭、小白算法等垂直类App也在近年快速成长，主打移动端刷题体验。

这些平台的共同特点是以题库为核心，通过大量题目练习帮助用户建立知识体系。但它们在面试场景模拟方面普遍投入不足，尤其是行为面试和HR面试这类偏软技能考查的环节，现有平台基本无法提供有价值的训练支持。随着大语言模型的普及，部分平台已开始尝试接入AI功能，但大多停留在答案解析和学习建议层面，距离真正意义上的全场景AI模拟面试还有较大差距。

在学术研究方面，国内高校和研究机构围绕智能教育、自适应学习等方向发表了大量成果。相关研究表明，基于用户行为数据的个性化推荐和学习路径优化能够显著提升学习效率，而结合知识图谱的题目关联分析也有助于帮助学习者系统性地掌握知识体系。这些研究成果为本系统的错题管理模块和知识库设计提供了理论参考。

### 1.3.2 国外研究现状及分析

在国际范围内，Pramp和Interviewing.io是两个颇具代表性的面试练习平台，它们采用真人对练的模式，通过匹配两位求职者互相扮演面试官和候选人来完成练习。这种方式的优势在于真实性强，但明显受制于用户规模和时间协调的难度，可扩展性有限。

HackerRank和Codility则主要聚焦于企业技术评估赛道，为企业提供在线笔试和代码评测工具，帮助企业筛选候选人，和面向求职者的备考工具定位有所不同。

学术层面，MIT、Stanford等高校的研究团队在自动评分、情感识别、自然语言理解等领域的研究成果，为构建智能面试评估系统提供了重要的理论基础。近年来，以GPT系列为代表的大语言模型的出现，让AI面试官的实现从设想变成了现实，多所高校已有相关的实验性系统研究成果发表。国外研究在技术路线上普遍领先，但本地化适配和中文语境的细粒度支持仍是需要在国内场景中重点解决的问题。

## 1.4 本文主要的研究工作

本文的主要工作集中在以下几个方面。

第一，完成了系统的整体架构设计和技术选型。采用前后端分离的B/S架构，后端基于SpringBoot框架构建，前端基于Vue.js框架开发，二者通过RESTful API进行通信。这种架构具备良好的扩展性和维护性，能够支撑后续功能的持续迭代。

第二，设计并实现了涵盖5种题型、多技术领域分类的结构化题库系统，支持单选题、多选题、编程题、简答题和系统设计题的存储与管理，并提供了随机抽题、分类筛选、全文搜索等功能，同时实现了用户答题后的自动判题和成绩统计。

第四，构建了知识库管理系统，支持按分类和难度浏览知识点，内容以Markdown格式存储并在前端渲染，用户可以通过了解、熟悉、掌握三个级别记录自己的学习进度。

第五，实现了错题本管理功能，系统在用户答错题目时自动记录错误信息，并根据复习次数和掌握情况智能安排后续复习时间，帮助用户克服遗忘曲线的影响。

第六，设计了学习数据分析模块，整合用户在题库练习、模拟面试、知识库学习等各板块产生的数据，通过ECharts图表直观呈现学习时长趋势、各分类正确率分布、知识掌握度等关键指标。

# 第2章 相关技术简介

## 2.1 SpringBoot框架

SpringBoot是在Spring Framework基础上发展而来的快速开发框架，由Pivotal团队维护，目前已成为Java生态中构建后端Web服务最主流的技术选型之一。Spring Framework本身功能强大，但其繁琐的XML配置和复杂的依赖管理长期以来都是开发者诟病的痛点，SpringBoot通过"约定优于配置"的设计理念很好地解决了这个问题——大量配置项都有合理的默认值，开发者只需要关注业务逻辑本身，而不必在配置文件上耗费过多精力。

本系统采用SpringBoot 2.7.14版本，它内嵌了Tomcat服务器，无需额外部署，直接打包成可执行的JAR文件就能运行，非常适合开发环境的快速调试和生产环境的快速部署。SpringBoot的自动配置机制（Auto-Configuration）能够根据类路径下的依赖自动推断并完成相关配置，比如检测到spring-boot-starter-data-jpa依赖后会自动配置JPA的EntityManager、事务管理器等组件，极大地降低了框架的使用门槛。

此外，SpringBoot Actuator提供了生产级别的应用监控端点，可以实时查看应用健康状态、Bean加载情况、HTTP请求统计等信息，为后期运维提供了便利。本系统的所有后端API均基于SpringBoot的@RestController注解构建，配合@RequestMapping系列注解完成路由映射，实现了清晰、规范的RESTful接口层设计。

## 2.2 Vue.js前端框架

Vue.js是一套用于构建用户界面的渐进式JavaScript框架，由尤雨溪创建并开源，因其轻量、易上手、生态丰富的特点在国内前端开发领域获得了极高的普及度。本系统使用Vue.js 2.6版本，配合Vue Router 3.5实现单页面应用（SPA）的路由管理。

Vue.js的核心是响应式数据绑定机制，通过Object.defineProperty实现对数据的监听，当数据发生变化时，视图层会自动重新渲染，开发者无需手动操作DOM，这使得复杂的界面交互逻辑变得容易维护。Vue的组件化开发模式将页面拆分成多个独立、可复用的组件，每个组件封装自己的模板、逻辑和样式，降低了不同功能之间的耦合度。

在本系统中，每个功能页面对应一个.vue单文件组件，例如Knowledge.vue负责知识库页面的展示与交互，Interview.vue负责AI模拟面试的完整流程。Vue Router通过路由守卫（router.beforeEach）实现了登录状态检查和教师端路由的角色权限验证，未登录用户会被重定向至登录页，没有教师角色的用户访问教师端路由时会被拦截并跳转到学生仪表盘页面。Axios作为HTTP客户端负责与后端API的数据交互，通过在main.js中将request实例挂载到Vue.prototype.$http，所有组件都可以便捷地发起HTTP请求。

## 2.3 Spring Data JPA

Spring Data JPA是Spring生态中用于简化数据访问层开发的框架，它在JPA（Java Persistence API）规范的基础上提供了更高层次的抽象，让开发者只需要定义接口，Spring在运行时会自动根据方法命名规则生成对应的SQL实现。本系统所有的数据库操作都通过Spring Data JPA的Repository接口完成，极大地减少了重复的CRUD代码。

以QuestionFavoriteRepository为例，接口中声明的findByUserIdAndTypeAndItemId方法，Spring Data JPA会自动解析方法名，生成"SELECT * FROM question_favorites WHERE user_id=? AND type=? AND item_id=?"这样的查询语句，开发者完全不需要手写SQL，也不需要编写任何实现类代码。对于复杂的联表查询或者聚合统计，Spring Data JPA支持通过@Query注解直接编写JPQL或原生SQL，保证了灵活性。

在数据库方面，系统的application.yml配置了spring.jpa.hibernate.ddl-auto: update，这意味着每次应用启动时Hibernate会自动根据实体类的注解定义来更新数据库表结构，开发阶段的数据库表变更无需手动执行DDL脚本，降低了开发迭代的成本。

## 2.4 Element UI

Element UI是饿了么前端团队基于Vue 2.x开发的企业级UI组件库，提供了按钮、表单、表格、对话框、菜单、图表容器等数十个高质量的基础组件，设计规范统一，交互体验良好，是目前Vue 2生态中使用最广泛的UI框架之一。本系统的所有前端界面都基于Element UI 2.15版本构建。

在知识库页面，利用el-dialog组件实现了知识点详情的弹窗展示，el-tag组件用于展示当前知识点的学习状态（了解/熟悉/掌握），el-progress展示各分类的练习进度。在题目练习页面，el-radio-group和el-radio组件配合实现了单选题的选项展示，el-table及其展开行功能用于在错题本中呈现题目详细信息和笔记内容。在教师端管理页面，el-form配合表单验证规则实现了题目和教程的新增与编辑功能。

值得一提的是，本系统在Element UI的基础上做了一套全局CSS变量主题方案，通过切换:root伪类下的CSS自定义属性，实现了亮色和暗色两套主题的动态切换，在不同环境和用户偏好下都能提供舒适的视觉体验。

## 2.5 ECharts数据可视化

ECharts是由百度开源并后来捐赠给Apache基金会的JavaScript图表库，目前已发展为国内最主流的前端数据可视化解决方案之一，5.x版本在性能和交互体验上都有显著提升。本系统在学习报告页面（StudyReport.vue）和仪表盘页面（Dashboard.vue）中大量使用了ECharts进行数据展示。

具体来说，学习时长趋势使用折线图（line chart）展示最近30天的每日学习时长变化；各题目分类的练习正确率分布使用柱状图（bar chart）对比展示，一眼就能看出哪些技术方向是薄弱点；知识点掌握度分布使用饼图（pie chart）展示了解、熟悉、掌握三个级别各占比例；各能力维度的综合评估使用雷达图（radar chart）呈现，算法、编码、数据库、网络、操作系统等多个维度一图尽览。这些可视化图表通过后端的/reports/study/{userId}接口获取聚合后的统计数据，在页面渲染时动态绑定到ECharts实例。

## 2.6 智谱AI大语言模型

智谱AI是国内领先的人工智能公司之一，其GLM（General Language Model）系列大语言模型基于清华大学研究成果发展而来，具备强大的中文理解和生成能力。本系统的AI模拟面试功能接入了智谱AI提供的API服务，调用GLM-4-Flash模型完成面试对话的生成。

在系统的ZhipuAIService服务类中，通过HTTP调用智谱AI的对话补全接口，将当前面试的历史对话上下文（最近5轮）以及面试官角色的系统提示词（system prompt）一起发送给模型，模型返回下一轮的面试官回复。系统提示词根据面试类型（技术面试/行为面试/HR面试）和目标岗位动态生成，引导模型扮演对应类型的面试官，确保生成内容的专业性和场景一致性。这种对话上下文窗口的管理方式，在保证面试连贯性的同时也控制了每次请求的token消耗。

## 2.7 本章小结

本章依次介绍了本系统涉及的主要技术栈，包括后端的SpringBoot、Spring Data JPA，前端的Vue.js、Element UI、ECharts，以及AI层面的智谱AI大语言模型。这些技术各有侧重，协同构成了系统的完整技术体系：SpringBoot负责后端业务逻辑和API服务，Spring Data JPA负责数据持久化，Vue.js和Element UI负责前端界面的构建与交互，ECharts负责学习数据的可视化展示，智谱AI则赋予了系统模拟真实面试场景的核心能力。
